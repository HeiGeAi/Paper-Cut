# Storyboard

## Scene 01，0.00–20.00 秒

| 项目 | 设计 |
| --- | --- |
| Purpose | 用一条镜头证明完整静帧可以被拆成真正改变构图的多层纸片动画 |
| Visual metaphor | 五张纸片从画外组装成 hero frame，中段炸开展示深度，再碰撞并重新落版 |
| Hero frame | 暖象牙色纸面上叠放一张撕边米色纸、一条珊瑚红纸带、一支深海军蓝箭头和一枚钴蓝圆纸片；圆纸片位于右上三分之一，箭头从左下指向圆片，左侧留出标注负空间 |
| Fixed background | 从获批原图空白区派生的 `scene-01-paper-stage`，只承担纸张纹理舞台 |
| Moving layers | 从获批原图提取的底板、红色纸条、上层纸板、方向箭头和蓝色圆片，共五层 |
| On-screen text | `不是推一张图`、`是五层重组`、`真正的拆层运动`、五层编号标签 |
| Motion | 0–4 秒五层从不同方向组装；5–6 秒局部回弹；7–10 秒炸开展示层级；10.5–12 秒重新组装；12.7 秒箭头碰撞圆片；14–18 秒多层视差推进；18–20 秒落版 |
| Transition | 单镜头，无场景切换；最后 1.2 秒保持完成构图 |
| Safety | 无敏感地理边界、无外部品牌、无人物身份声称 |

## Gate 记录

- Gate 1：本次测试请求冻结为单镜头 20 秒无旁白演示；2026-08-30 根据用户反馈升级为五层强运动版本。
- Gate 2：图像模型 1 次尝试；音频、视频模型 0 次；其余处理为本地派生。
- Gate 3：V1 因运动幅度和层数不足被否决；本轮输出 Motion V2 draft preview，等待用户验收。
