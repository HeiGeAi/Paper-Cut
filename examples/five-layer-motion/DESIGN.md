# Design

- Canvas：1920×1080，16:9，30fps。
- Paper stock：暖象牙色底纸、米色撕边中景纸、珊瑚红和钴蓝印刷纸。
- Print process：半调网点、轻微套色偏移、纸纤维和原生方向性阴影。
- Typography：PingFang SC / system sans，深海军蓝；大标题 80px，辅助标注 18–28px。
- Motion：五层纸片分别使用 slap、overshoot、exploded view、reassembly 和 collision reaction；文字使用 slide / stamp；末段使用 5.5% parallax push。
- Constraint：保持 hero frame 作为唯一美术基准，次级标签保持 HTML 可编辑，不使用渐变背景、视频模型或随机动画。
